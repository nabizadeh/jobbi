Place your resume file(s) in this folder, then run Claude Code from the jobbi root directory.

Supported formats:
  .pdf    — preferred (used as visual reference for LaTeX output)
  .docx   — Microsoft Word
  .doc    — legacy Microsoft Word
  .odt    — OpenDocument (LibreOffice)
  .tex    — LaTeX source
  .md     — Markdown (read directly, no conversion needed)
  .txt    — Plain text (read directly, no conversion needed)

You can place multiple resumes here. jobbi will read all of them and use the most
relevant one as the base for each job application.

If you provide both a PDF and a plain-text version of the same resume, the PDF
will be used as the visual formatting reference.

Optional: place a photo here as photo.jpg (or .jpeg/.png) if your market requires
one (e.g. Denmark, Germany). See agents/resume-style.md Recipe 1 to activate it.

Optional: place a writing sample here as writing_sample.txt or writing_sample.md
to help jobbi match your tone when generating cover letters.

Do NOT rename or delete this file — it keeps the folder visible in git.
